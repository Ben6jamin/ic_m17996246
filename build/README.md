# Build Directory

This folder contains the runnable Python executable archive generated by:

```bash
python3 build_project.py
```

The generated file is:

```text
build/ic_project.pyz
```

Run it with `python3 build/ic_project.pyz <command>`. Python does not create C/C++ `.o` object files, so the `.pyz` archive is the project executable. All generated build artifacts remain under this folder as required.
