# Authentic Screenshot Checklist

Take these screenshots yourself on your laptop. Keep VS Code visible, including the Explorer/sidebar and terminal prompt, so the images clearly show that you ran the program.

Before Task 1, run `python3 build_project.py`. The task screenshots should use `python3 build/ic_project.pyz ...` so the report proves that you ran the executable from the required build folder.

1. Task 1 frequency terminal: show the command, number of letters, and the full a-z table. Enlarge the terminal vertically if necessary.
2. Task 1 plot: open `data/frequency_plot.png` inside VS Code and capture the chart with the VS Code tab visible.
3. Task 1 IC terminal: show `Index of Coincidence: ...` and the command used.
4. Task 2 encryption: show the command, 100-letter plaintext, key, and uppercase ciphertext.
5. Task 2 decryption: show the command, uppercase ciphertext, key, and recovered lowercase plaintext.
6. Task 3 attack: first capture the key-length table; then capture the key-letter scores and recovered key.
7. Task 4: show the `attack-folder` command and summary for all shared files.
8. Optional GitHub evidence: show the repository page after pushing, but do not use this instead of program-output screenshots.

Do not paste made-up terminal images into the report. Insert only the screenshots you capture after running these commands.
